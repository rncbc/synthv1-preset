# SynthkV1 Factory Presets

Collaborative repository of factory presets for SynthV1.
If you want to submit your own presets, we would love to include them as long as they meet the following requirements.

## Requirements

### 1. Mandatory Universal License: Creative Commons Zero (CC0) 1.0
Your presets must be released strictly under the **Creative Commons Zero (CC0) 1.0 Universal (Public Domain)** license.

**Reasons:**
A preset must be easily editable and shareable. Licenses that strictly require attribution mean creating extra tracking documentation. This is neither practical nor viable.

However, recognition is fundamental to us. We highly recommend including your author metadata.

### 2. Immutability of Presets

**It is strictly forbidden to update or overwrite an existing preset or sample.** 
* If you wish to improve or create variations of a factory preset, you must save and submit it under a **different name**.

### 3. Metadata
Before submitting your preset, open it with a text editor and include the metadata in the header.

**Example:**

~~~
<!DOCTYPE synthv1>
<preset name="MyPreset" collection="Vee One Factory" author="MyName (or alias)" license="Creative Commons Zero (CC0) 1.0 Universal">
 <comments>
    You can add a comments tag to:

    * Specify technical data
    * Usage recommendations
    * Credit the original preset if it is a variant
    * Etc
 </comments>
~~~

### Support and Suggestions

We do not handle GitHub issues. The place to submit your questions and suggestions is the [official SynthV1 forum](https://rncbc.org).

### Submitting Presets

Only preset submissions are allowed, not banks. If you feel it is necessary to add more banks, raise it in the official SynthV1 forum and we will discuss it.

**Submission methods**

* **GitHub:** Create a branch of this repository and push a commit with your presets.

* **[Official SynthV1 forum](https://rncbc.org):** Register and create a post with your presets attached as a compressed ZIP file.
